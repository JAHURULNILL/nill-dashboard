# নীলের ড্যাশবোর্ড

নীলের (মোঃ জাহুরুল হক) ব্যক্তিগত ড্যাশবোর্ড — হালকা থিমের, সুপার-ফাস্ট, ভ্যানিলা HTML/CSS/JS দিয়ে তৈরি স্ট্যাটিক ওয়েবসাইট (কোনো ফ্রেমওয়ার্ক/বিল্ড স্টেপ নেই)। Vercel থেকে ডিপ্লয় করা হয়।

## সেকশন
১. **হোম** — শুভেচ্ছা, ঢাকার তারিখ, স্ট্যাট চিপ, আজকের উক্তি, আজকের রুটিন, আসন্ন ডেডলাইন
২. **চাকরি** — ১১৩টি আসল আবেদনের তালিকা, চ্যানেল ফিল্টার, ডেডলাইন কাউন্টডাউন, স্ট্যাটাস বদল (localStorage-এ সেভ), শর্টলিস্ট ব্লক
৩. **শেখা** — MS Word মডিউল: অগ্রগতি, আসন্ন পাঠ, র‍্যান্ডম ১০-প্রশ্নের MCQ অনুশীলন, Word-মকআপ উদাহরণ কার্ড; Excel "শীঘ্রই আসছে"
৪. **উক্তি** — প্রতিদিন ১০টি নতুন উক্তি (প্রতি বিভাগে ২টি), পিন করা যায়
৫. **খবর** — বাংলাদেশ / প্রযুক্তি ও AI / বিশ্ব — `scripts/fetch_news.py` দিয়ে প্রতিদিন তাজা
৬. **আশ্চর্য তথ্য** — প্রতিদিন নতুন ১০টি
৭. **আজকের উন্নতি** — প্রতিদিন ১০টি টিপস + দিনের রুটিন
৮. **পিন করা** — পিন করা সব আইটেম এক জায়গায়

## গুরুত্বপূর্ণ নিয়ম (product rule)
- উক্তি, তথ্য ও টিপস **প্রতিদিন নতুন** — গতকালেরটা সরে যায়। তারিখ থেকে deterministic নির্বাচন (`dailyPick`), তাই সারাদিন একই সেট, পরদিন নতুন সেট।
- পিন করা আইটেম **পিন লিস্টে থেকে যায়** — localStorage-এ সেভ থাকে।

## ফাইল কাঠামো
```
index.html          # সিঙ্গেল-পেজ অ্যাপ
style.css           # লাইট থিম ডিজাইন-টোকেন
app.js              # সব রেন্ডারিং ও লজিক
data/jobs.json      # আবেদন + শর্টলিস্ট + কাউন্টার
data/quotes.json    # ৫০টি উক্তি (৫ বিভাগ)
data/quiz.json      # Word MCQ ব্যাংক (৩০) + টপিক + উদাহরণ কার্ড
data/facts.json     # ১২০টি আশ্চর্য তথ্য
data/growth.json    # ১২০টি উন্নতি-টিপস + দৈনিক রুটিন
data/news.json      # প্রতিদিন regenerate হয় (স্ক্রিপ্ট দিয়ে)
scripts/fetch_news.py  # stdlib-only RSS/Atom ফেচার (cron থেকে চলে)
```

## দৈনিক আপডেট
ক্রন জব প্রতিদিন সকালে চলে: `python3 scripts/fetch_news.py` → `data/news.json` নতুন করে লেখা → GitHub-এ কমিট-পুশ → Vercel অটো-ডিপ্লয়।
